# Mama Njeri Restaurant Website

A responsive static restaurant website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content and menu
- `style.css` — layout, colours and responsive design
- `script.js` — mobile navigation and demo order form

## Publish with GitHub Pages
1. Extract this ZIP file.
2. Open GitHub and create a new public repository, for example `mama-njeri-website`.
3. Upload the files inside this folder (not the ZIP itself). Make sure `index.html`, `style.css` and `script.js` are in the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Wait a few minutes and open the website address shown in the Pages section.

## Before publishing
- Replace the contact phone and location placeholders in `index.html`.
- The order form is currently a front-end demonstration. It does not send orders or payments. A real WhatsApp order link can be connected after the restaurant phone number is provided.
- Food photos are loaded from external image URLs, so the website needs an internet connection to display them. For a final submission, you may download properly licensed images and place them in the `images` folder, then update the image paths.
